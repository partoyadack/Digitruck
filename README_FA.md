# DIGITRUCK — فروشگاه فول‌استک

## اجرا در ویندوز
1. Python 3.11+ نصب کن و گزینه Add Python to PATH را فعال کن.
2. ZIP را Extract کن و پوشه DIGITRUCK_PRO را باز کن.
3. در نوار آدرس File Explorer بنویس `cmd` و Enter بزن.
4. این دستورات را اجرا کن:
```bat
py -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python app.py
```
5. مرورگر: `http://127.0.0.1:5000`

## ورود اولیه مدیر
ایمیل: `admin@digitruck.local`
رمز: `ChangeThisAdminPassword123!`
این رمز فقط برای شروع محلی است؛ قبل از انتشار، `.env` را تنظیم کن و رمز قوی بگذار. اگر مدیر اولیه قبلاً ایجاد شده، تغییر متغیر رمز در `.env` رمز موجود را عوض نمی‌کند؛ برای راه‌اندازی مجدد کاملاً تازه می‌توانی پس از بکاپ، دیتابیس `instance/digitruck.db` را حذف کنی (این کار همه کاربران و سفارش‌ها را حذف می‌کند).

## اجرای اندروید
ZIP را استخراج کن، Termux را از منبع رسمی نصب کن، وارد پوشه پروژه شو و اجرا کن:
```bash
pkg update
pkg install python
pip install -r requirements.txt
cp .env.example .env
python app.py
```
سپس در مرورگر گوشی `http://127.0.0.1:5000` را باز کن. برای توقف سرور Ctrl+C را بزن.

## امکانات
- فروشگاه واکنش‌گرا، دسته‌بندی، جستجو، مرتب‌سازی و صفحه جزئیات
- ثبت‌نام/ورود و رمزهای هش‌شده
- سبد خرید، بررسی موجودی، ثبت سفارش با پرداخت هنگام تحویل
- پیگیری سفارش و پنل مدیر برای افزودن/ویرایش/پنهان‌کردن محصولات و تغییر وضعیت سفارش
- SQLite، محافظت CSRF و بررسی موجودی هنگام ثبت سفارش

## محدودیت‌های لازم برای کسب‌وکار واقعی
این یک کدبیس فول‌استک قابل اجراست، نه فروشگاه میزبانی‌شده. پرداخت آنلاین واقعی تا اتصال درگاه معتبر و پیاده‌سازی callback/تأیید تراکنش فعال نیست. تصاویر و اطلاعات اولیه کاتالوگ نمونه‌اند و باید با تصاویر واقعی، سازگاری دقیق قطعات، قیمت/موجودی واقعی، اطلاعات تماس و سیاست‌های ارسال/مرجوعی جایگزین شوند. برای انتشار عمومی، HTTPS، بکاپ، تنظیم SECRET_KEY قوی، سرور production، سیاست حریم خصوصی و آزمون امنیتی لازم است. سرور توسعه Flask را مستقیم روی اینترنت عمومی منتشر نکن.
